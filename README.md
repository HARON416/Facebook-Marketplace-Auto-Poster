## ✅ Features

- Post multiple items automatically.
- Works with product categories such as phones, electronics, and furniture.
- Runs locally—no unofficial Facebook API required.
- Saves your Facebook session in a dedicated local Chrome profile.
- Automatically fills in product details and uploads images.
- Selects suggested audience groups before publishing.
- Optionally rewrites descriptions with Gemini.
- Free to use—no subscriptions or hidden fees.

---

## ✅ How It Works

Facebook Marketplace Auto Poster runs locally on your computer. Add each product's photos and listing details to its own folder, then run the tool.

It opens Chrome, enters the title, price, category, condition, description, and product tags, uploads up to six images, and publishes each listing—just as you would manually, only faster.

You remain in control of your Facebook account and posting activity.
